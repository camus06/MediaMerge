Getting started

Every MediaMerge workspace starts with a source upload. Once a file is received, it is versioned, checksummed, and queued for processing before anything is made visible to a viewer.

Working with assets

An asset holds its own identity independent of any single file. Replacing a version never breaks links, credits, or history.

  • Upload accepts common video, audio, and image formats.
  • Metadata fields are extensible per workspace.
  • Processing status is visible at every stage.

Rights and licensing

Each asset can carry one or more license records describing owner, territory, duration, and permitted tiers. Playback is only ever a confirmation of a right already granted.

Playback and delivery

Approved renditions are delivered through short-lived, signed access rather than public files, so a permission change takes effect immediately.
